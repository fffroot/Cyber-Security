### 🟢 Блок 1: Криптография и целостность данных
*Цель: Научиться работать с хешами, шифрованием и кодированием на практике.*

1. **File Integrity Monitor (FIM)**  
   - **Описание:** Скрипт, который вычисляет хеши (SHA-256) файлов в заданной директории, сохраняет их в базу (JSON/SQLite) и при повторном запуске сообщает об изменениях.  
   - **Чему учит:** Работа с файловой системой, хеширование (`hashlib`), обнаружение несанкционированных изменений.
2. **Multi-format Encoder/Decoder**  
   - **Описание:** Инструмент для кодирования и декодирования строк в Base64, Hex, URL-encoding и ROT13.  
   - **Чему учит:** Обфускация данных, работа со строками, понимание того, как злоумышленники прячют payloads.
3. **XOR Cipher Tool**  
   - **Описание:** Реализация шифрования и дешифрования файлов или текста с помощью XOR с заданным ключом.  
   - **Чему учит:** Побитовые операции, основы симметричного шифрования, анализ вредоносного ПО (многие малвари используют простой XOR).
4. **Archive Brute-Forcer (ZIP/RAR)**  
   - **Описание:** Скрипт, который пытается открыть запароленный архив, перебирая слова из переданного словаря (wordlist).  
   - **Чему учит:** Работа с библиотеками (`zipfile`), перебор (brute-force), обработка исключений.

### 🟢 Блок 2: Сетевая разведка и сканирование
*Цель: Понять, как работают сетевые протоколы на уровне сокетов и запросов.*

5. **TCP Port Scanner (Connect Scan)**  
   - **Описание:** Сканирование диапазона портов на целевом IP с использованием TCP-рукопожатия (многопоточное для скорости).  
   - **Чему учит:** Библиотека `socket`, многопоточность (`threading` или `concurrent.futures`), основы TCP/IP.
6. **ICMP Ping Sweeper**  
   - **Описание:** Скрипт, который отправляет ICMP-запросы (ping) на всю подсеть (например, 192.168.1.0/24) и выводит список живых хостов.  
   - **Чему учит:** Работа с `subprocess` или `scapy`, сетевое обнаружение, маскировка в сети.
7. **DNS & Whois Recon Tool**  
   - **Описание:** Сбор информации о домене: IP-адреса, NS-серверы, MX-записи и данные Whois.  
   - **Чему учит:** Протокол DNS, работа с внешними API или библиотеками (`dnspython`, `python-whois`), пассивная разведка (OSINT).
8. **Subdomain Enumerator**  
   - **Описание:** Перебор поддоменов по словарю с проверкой их существования через DNS-запросы.  
   - **Чему учит:** Массовые сетевые запросы, обработка таймаутов, расширение поверхности атаки.

    - **Описание:** Bash/Python скрипт, который архивирует важные директории, шифрует архив (например, через GPG или пароль на ZIP), вычисляет хеш и сохраняет в безопасное место.

### 🟡 Блок 1: Продвинутый сетевой анализ и манипуляция протоколами
*Цель: Научиться работать с сырыми пакетами, понимать аномалии в трафике и манипулировать сетевым уровнем.*

1. **TCP SYN Stealth Scanner**  
   - **Описание:** Реализация сканера, который отправляет SYN-пакеты, но не завершает рукопожатие (не отправляет ACK), чтобы не оставлять записей в логах целевой системы.  
   - **Чему учит:** Raw sockets, структура TCP-заголовков, работа с привилегиями root, отличие от Connect-сканирования.  
   - **Технологии:** Python (`scapy` или `socket` с `SOCK_RAW`).
2. **DNS Tunneling Detector**  
   - **Описание:** Анализатор DNS-трафика (из PCAP-файла или live-перехвата), который выявляет аномалии: необычно длинные доменные имена, высокую энтропию в поддоменах или аномальную частоту запросов.  
   - **Чему учит:** Статистический анализ, энтропия Шеннона, методы эксфильтрации данных.  
   - **Технологии:** Python (`scapy`, `math`), pandas (для анализа).
3. **Network PCAP Credential Extractor**  
   - **Описание:** Инструмент, который парсит `.pcap` файлы и извлекает из них открытые учетные данные (HTTP Basic Auth, FTP, Telnet, незашифрованный SMTP).  
   - **Чему учит:** Парсинг сетевых протоколов, регулярные выражения для поиска паттернов, работа с библиотекой `pyshark` или `scapy`.  
   - **Технологии:** Python, Wireshark/tshark (как зависимость).
4. **Custom ARP Spoofer & Mitigator**  
   - **Описание:** Два режима: 1) проведение ARP-спуфинга между двумя хостами в твоей виртуальной сети; 2) режим защиты, который отслеживает изменения в ARP-таблице и блокирует атакующего.  
   - **Чему учит:** Протокол ARP, MITM-атаки, динамическое взаимодействие с сетевым стеком ОС.  
   - **Технологии:** Python (`scapy`), Bash (для манипуляции `iptables` или `arp` таблицей).
5. **Rogue DHCP Server Detector**  
   - **Описание:** Скрипт, который слушает сеть и анализирует DHCP OFFER-пакеты, предупреждая, если в сети появляется DHCP-сервер с MAC-адресом, отличным от доверенного.  
   - **Чему учит:** Протокол DHCP (DORA), сетевой мониторинг, защита периметра LAN.  
   - **Технологии:** Python (`scapy`), конфигурационные файлы (JSON/YAML для доверенных MAC).

10. **Web Directory Fuzzer with Smart Filtering**

    - **Чему учит:** Эвристика в веб-сканировании, многопоточность, обработка edge-кейсов HTTP.

### 🔴 Блок 1: Продвинутый Reverse Engineering и Exploit Development
*Цель: Научиться работать с бинарными файлами на низком уровне, обходить современные защиты и автоматизировать поиск уязвимостей.*

1. **Полиморфный кодировщик шеллкода (Polymorphic Shellcode Encoder)**  
   - **Описание:** Инструмент, который не просто шифрует шеллкод (как XOR), а генерирует уникальный "декодер" (stub) для каждого запуска, меняя структуру кода, чтобы обойти статические сигнатуры антивирусов.  
   - **Чему учит:** Ассемблер (x86/x64), обход AV/EDR, полиморфизм, работа с бинарными данными.  
   - **Технологии:** Python, Assembly, библиотеки для генерации бинарников.
2. **Автоматический генератор ROP-цепочек (ROP Chain Builder)**  
   - **Описание:** Скрипт, который анализирует ELF/PE-файл, извлекает из него "гаджеты" (кусочки кода, заканчивающиеся на `ret`) и автоматически строит цепочку для выполнения полезной нагрузки (например, вызова `execve`).  
   - **Чему учит:** Механика переполнения буфера, обход DEP/NX, работа с дизассемблерами (через API, например, `r2pipe` или `angr`).  
   - **Технологии:** Python, `angr` или `r2pipe` (Radare2).
3. **Генератор Harness-ов для фаззинга (Fuzzing Harness Generator)**  
   - **Описание:** Инструмент, который берет исходный код C/C++ функции, автоматически оборачивает её в "harness" (обертку) для `libFuzzer` или `AFL++`, генерирует Makefile и начальный corpus.  
   - **Чему учит:** Методология fuzzing, компиляция, поиск уязвимостей на этапе разработки.  
   - **Технологии:** Python, парсинг AST (Abstract Syntax Tree), Bash.
4. **Кастомный пакер/анпакер исполняемых файлов (PE/ELF Packer)**
