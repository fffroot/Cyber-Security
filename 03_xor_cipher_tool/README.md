# XOR Cipher Tool

CLI-инструмент для симметричного шифрования и дешифрования файлов с использованием алгоритма XOR с повторяющимся ключом.

## 🚀 Возможности
- Симметричное шифрование (одна функция для encrypt и decrypt).
- Поддержка многосимвольных ключей (циклически повторяются для файлов любого размера).
- Работа с любыми бинарными файлами (изображения, исполняемые файлы, шеллкоды).
- Безопасный вывод зашифрованных данных в терминал в Hex-формате (защита от непечатных символов).

## 💻 Использование

### Шифрование с сохранением в файл
```bash
python xor_cipher.py -i secret.txt -k "my_super_key" -a encrypt -o encrypted.bin
```

### Дешифрование с выводом в терминал (Hex)
```bash
python xor_cipher.py -i encrypted.bin -k "my_super_key" -a decrypt
```

### Дешифрование с сохранением в файл
```bash
python xor_cipher.py -i encrypted.bin -k "" -a decrypt -o decrypted.txt
```

## 🛡️ Архитектура
Инструмент использует `itertools.cycle` для эффективного применения ключа к данным произвольной длины без избыточного потребления памяти.
