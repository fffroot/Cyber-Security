# TCP Port Scanner (Multi-threaded)

Высокопроизводительный многопоточный сканер TCP-портов, написанный на C. Поддерживает сканирование диапазонов портов, ограничение количества одновременных потоков (Semaphore) и автоматическое определение сервисов через Banner Grabbing.

## 🚀 Возможности

- **TCP Connect Scan**: Полное TCP-рукопожатие (3-way handshake) для точного определения состояния порта.
- **Многопоточность (`pthread`)**: Параллельное сканирование для максимального быстродействия.
- **Контроль ресурсов (Semaphore)**: Ограничение максимального числа одновременных потоков (по умолчанию 500), предотвращающее исчерпание памяти и лимитов ОС (`ulimit`).
- **Banner Grabbing**: Автоматическая попытка прочитать приветственное сообщение сервиса (SSH, HTTP, FTP и др.) с использованием `select()` и `recv()`.
- **Настраиваемый таймаут**: Гибкая настройка времени ожидания ответа (`TIMEOUT_MS`), критичная для сканирования хостов за фаерволами.
- **Чистая архитектура**: Отсутствие утечек файловых дескрипторов (единая точка закрытия `close()`), обработка всех ошибок `errno`.

## 📋 Требования

- **ОС:** Linux / macOS (POSIX-совместимая)
- **Компилятор:** GCC или Clang
- **Библиотеки:** `pthread`, стандартная библиотека C

## 🛠 Компиляция

```bash
# Ручная компиляция
gcc -Wall -Wextra -pthread -o scanner port_scanner.c

# Или через Makefile
make
make clean  # Очистка
```

## 💻 Использование

```bash
./scanner <IP-адрес> <Начальный_порт> <Конечный_порт>
```

### Примеры:

**1. Быстрое сканирование популярных портов (1-1024):**
```bash
./scanner 192.168.1.1 1 1024
```

**2. Полное сканирование всех 65535 портов:**
```bash
./scanner scanme.nmap.org 1 65535
```

**3. Проверка конкретного порта:**
```bash
./scanner 127.0.0.1 80 80
```

## 🏗 Архитектура и ключевые концепции

### 1. Ограничение потоков (Semaphore)
Вместо создания 65 000 потоков одновременно (что приводит к `OutOfMemory` или исчерпанию `pid_max`), используется семафор:
```c
sem_init(&thread_sem, 0, MAX_CONCURRENT_THREADS);
// ... в цикле:
sem_wait(&thread_sem); // Ждём свободный слот
pthread_create(...);
// ... в потоке:
sem_post(&thread_sem); // Освобождаем слот
```

### 2. Banner Grabbing через `select()`
После успешного `connect()` мы не блокируем поток бесконечно. Мы используем `select()` с таймаутом 1 секунда, чтобы проверить, есть ли данные для чтения, и если да — читаем баннер через `recv()`.

### 3. Обработка ошибок и утечек
Функция `scan_port()` использует паттерн "Single Exit Point" (единая точка выхода), гарантируя, что `close(sock)` вызывается **всегда**, предотвращая утечку файловых дескрипторов при сканировании тысяч портов.
